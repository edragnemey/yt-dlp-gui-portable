YtDlpGUI Portable 1.1.0
========================

使用方法：

1. 保持本文件、YtDlpGUI.exe 和 tools 文件夹在同一个目录中。
2. 双击 YtDlpGUI.exe。
3. 粘贴网址，选择保存目录和格式，然后点击“开始下载”。

目标电脑不需要安装 Python、yt-dlp、FFmpeg 或 Deno，也不需要配置 PATH。

如果 YouTube 要求登录，请在界面的“浏览器 Cookie”中选择已经登录的浏览器。

请只下载你有权保存的内容，并遵守网站服务条款和当地法律。

项目主页和更新地址见 GitHub Release 页面。
